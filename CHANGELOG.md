# Catatan Perubahan

## Versi GitHub Pages

- Mengganti Tailwind Play CDN dengan CSS hasil kompilasi lokal.
- Menambahkan workflow GitHub Actions untuk publikasi otomatis ke GitHub Pages.
- Menambahkan README berbahasa Indonesia dan instruksi menjalankan serta menerbitkan situs.
- Memperbaiki validasi dan pembatasan nilai progres yang disimpan di browser.
- Memastikan generator soal selalu menghasilkan tiga pilihan jawaban positif dan unik.
- Memperbaiki pelepasan material efek ledakan untuk mengurangi kebocoran memori grafis.
- Memperbaiki kontrol keyboard: tombol spasi dapat ditembakkan terus saat ditahan, shortcut tidak berulang karena key repeat, dan input pengaturan tidak terganggu.
- Memulihkan status tombol ketika jendela browser kehilangan fokus.
- Menambahkan pesan yang lebih informatif jika Three.js atau WebGL gagal dimuat.
- Memperbaiki aksesibilitas kontrol dan dukungan preferensi reduced motion.
- Memperbaiki indikator progres agar menunjukkan soal yang berhasil dijawab.
